# Мини-корпус для локального стенда

Генератор берёт четыре файла из `data/samples`, добавляет три исходных синтетических
регламента и 17 новых из `expanded_regulations.json`, затем собирает манифест.
Новые тексты синтетические и предназначены для демонстрации, включая два сценария
с возвратом лицензии и доставкой ключа. Для другого места хранения образцов укажите
`--samples-dir`.
Результат пишется в `data/docs` или каталог из `--docs-dir`.

```bash
uv run python scripts/synth/generate.py
uv run python scripts/synth/generate.py --revision 2
```

Во второй редакции срок проверки маржинальности меняется с трёх рабочих дней на один.
Запускайте вторую команду при работающем наблюдателе, чтобы проверить переиндексацию.
В манифесте остаётся одна активная редакция документа, а неизменившиеся файлы сохраняют хэши.
Контроль маржинальности открыт всем сотрудникам. Регламент финансового архива доступен
учётке `employee_fin`. Контрольные вопросы лежат в `eval/questions.yaml`.

На уже работающем стенде каталог `data/docs` сохраняется между релизами, поэтому
новые документы нужно собрать отдельно после обновления кода:

```bash
uv run python scripts/synth/generate.py --docs-dir "$HOME/srv/regagent_prod/data/docs"
```

Knowledge увидит обновлённый манифест и поставит новые документы в очередь индексации.
Повторный запуск генератора не меняет байты неизменившихся DOCX.
