## Правила ведения

- Решение, которое меняет архитектуру, контракт или поведение агента, сначала записывается в `09-decisions.md` (что, почему, что отвергли), потом попадает в код.
- Контракты (`06-contracts.md`) меняются только вместе с тестами, которые их проверяют.
- Устаревшее не удаляем молча: помечаем «заменено решением D-NN».

## Короткий словарь

Только то, что не очевидно из контекста.

| Термин | Значение |
| --- | --- |
| ОКК | Отдел контроля качества заказчика. Разбирает спорные и неотвеченные вопросы; только ОКК может публиковать записи практики |
| Практика | Подтверждённое ОКК знание, которого нет в тексте регламента (законы, налоги, регионы, неочевидные следствия). Привязана к пунктам регламента; при противоречии с регламентом приоритет у практики |
| Область | Направление бизнеса, чьи правила применяются к вопросу (например ДИБ, ДБРЦТ, «общий») |
| OKF | Формат хранения знаний (спецификация knowledge-catalog Google Cloud, v0.2): markdown с YAML-шапкой в git. Источник истины для редакций документов, практики и глоссария |
| ДИБ | Дирекция информационной безопасности (наше сокращение; в документах — «Дирекция ИБ») |
| ДБРЦТ | Департамент бизнес-решений и цифровой трансформации |
