# Первая рабочая версия (этапы 0–1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вход → чат → ответ со ссылками на пункты по документам из папки; два уровня доступа; области и их память; переиндексация при изменении файла.

**Architecture:** Два Python-сервиса в uv-workspace: `knowledge` (LightRAG как библиотека, workspace на уровень доступа, индексация и поиск в одном процессе) и `backend` (Aegra + Deep Agents во внешнем графе guard → агент → проверка ссылок). Общие контракты — пакет `regagent-common`. Веб — React. Всё в docker compose.

**Tech Stack:** Python 3.12+, uv, FastAPI, LightRAG, Docling, asyncpg, aio-pika, Aegra, Deep Agents, LangGraph, PyJWT, Postgres (pgvector + AGE), RabbitMQ, Keycloak, Caddy, React + Vite + TS + Tailwind + shadcn/ui.

**Spec:** `dev_docs/01-concept.md` … `dev_docs/09-decisions.md`; задачи и роли — `dev_docs/10-work-plan.md`.

## Global Constraints

- Python `>=3.12,<3.14`; зависимости добавляются `uv add <пакет>` (берётся актуальная версия), версии фиксирует `uv.lock`.
- Все настраиваемые параметры — переменные из `06-contracts.md#переменные-env` через pydantic-settings; новых констант-«магических чисел» в коде нет.
- Права доступа определяет только код: уровни — из токена, у инструментов агента нет аргументов уровня/пользователя.
- Заголовок фрагмента — ровно формат `⟦doc=<doc_id> v=<version> clause=<clause> area=<area> level=<level>⟧` (из `03-knowledge-service.md`), только через `regagent_common.fragments`.
- `fragment_id`: `<doc_id>@<version>#<clause>` для регламентов, `practice:<practice_id>` для практики.
- workspace уровня — `lvl_<level>`; служебный пустой workspace `lvl__sentinel` инициализируется первым.
- «Нет прав» и «нет документа» неразличимы для вызывающего (404).
- Тексты для пользователя — на русском.
- Порядок по каждой задаче: тест → падение → код → зелёные тесты → `uv run ruff check && uv run mypy` → коммит.

## Review Focus

1. Документ без нумерации пунктов (только заголовки и абзацы) — должен индексироваться фрагментами по заголовкам, а не теряться. Тест: Task P1-A4 `test_unnumbered_document_falls_back_to_headings`.
2. Файл пересохранён без изменения содержимого — переиндексации быть не должно. Тест: Task P1-A2 `test_same_sha_produces_no_job`.
3. Два документа с одинаковым `doc_id` в манифесте — оба помечаются ошибкой, остальные индексируются. Тест: Task P1-A1 `test_duplicate_doc_id_marks_both_invalid`.
4. LightRAG вернул текст без нашего заголовка (описание сущности, обрывок) — фрагмент выбрасывается, а не уходит агенту с пустыми метаданными. Тест: Task P1-B2 `test_fragment_without_header_is_dropped`.
5. Токен без claim с группами — пользователь получает только `public`, а не ошибку 500. Тест: Task P1-C1 `test_token_without_groups_gets_public_only`.
