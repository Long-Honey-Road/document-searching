# Keycloak

Сюда кладётся экспорт realm `regagent` (`regagent-realm.json`), который импортируется при старте.
Его собирает задача P0-3 плана: клиент `regagent-web` (public, PKCE), группы `/levels/closed_fin`,
роли `qc` и `admin`, маппер групп в токен, защита от перебора паролей, саморегистрация выключена,
тестовые учётки для демо.
