# data

Локальные данные, в git не попадают (кроме этого файла и пустых папок).

- `docs/` — исходные документы и `manifest.yaml` (на стенде монтируется в knowledge как `DOCS_DIR`).
- `okf/` — git-репозиторий OKF, который ведёт knowledge (`OKF_DIR`).

Реальные образцы заказчика сюда кладутся вручную и перед загрузкой на стенд обезличиваются.
